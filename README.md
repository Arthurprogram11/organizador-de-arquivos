# Organizador Automático de Arquivos

![Status](https://img.shields.io/badge/status-em%20desenvolvimento-58A6FF?style=flat-square)
![Python](https://img.shields.io/badge/Python-em%20aprendizado-3776AB?style=flat-square&logo=python&logoColor=white)

Projeto em Python para organizar arquivos automaticamente, criado como parte do meu aprendizado e portfólio para estágio em tecnologia.

## Objetivo

Praticar fundamentos de Python em um problema real, com atenção especial à segurança das operações, ao tratamento de erros e à organização do código.

## Escopo inicial

- identificar os arquivos de uma pasta;
- classificá-los de acordo com suas extensões;
- movê-los para pastas correspondentes;
- evitar sobrescritas e operações inseguras;
- tratar erros de acesso e manipulação de arquivos;
- adicionar testes básicos para os comportamentos mais importantes.

## Tecnologias previstas

- Python;
- `pathlib`;
- `shutil`;
- tratamento de exceções;
- `pytest` para testes básicos.

## Estado atual

O projeto está em desenvolvimento. A estrutura inicial foi preparada e o código será publicado progressivamente, acompanhado de instruções de execução e exemplos reais.
